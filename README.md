## 버전 규칙

문서가 여러 벌 떠돌면 어느 게 기준인지 알 수 없게 됩니다. 아래를 지킵니다.

1. **파일은 이름당 하나.** `PLAN_v2.md`, `PLAN_최종.md` 같은 사본을 만들지 않습니다. 같은 파일을 고칩니다.
2. **버전은 문서 맨 위 한 곳에만** 적습니다 — `**문서 버전:** v1.0 · 2026-09-14`
3. **올리는 기준**
   - 오타·표현 수정 → 버전 안 올림
   - 내용 추가·수정 → 소수점 (v1.0 → v1.1)
   - 기능 범위나 데이터 모델 변경 → 정수 (v1.x → v2.0)
4. **변경 이력은 문서 맨 끝** `## 변경 이력` 표에 한 줄. 이전 버전 전문을 문서 안에 남기지 않습니다.
5. **순서** — 기능·데이터가 바뀌면 `PLAN.md`를 먼저 고치고, 그다음 `FIGMA_SPEC.md`를 맞춥니다. 뒤집지 않습니다.
